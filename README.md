# Celebrity Jai Alai

Limited-edition celebrity match-ups built on the Fantasy League Jai Alai game engine.

The site is the files in this folder (`index.html` is the game). The page opens on the match-up art; the player picks who to play as, a mode (Professional, Amateur or Cocktail Table) and whether to play with sponsor pop-outs.

It is built from the Fantasy League Jai Alai source: each new match-up is a new VS image, two face crops and a few lines of settings.
